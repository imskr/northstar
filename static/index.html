Volatility basis—

Simulated as a lognormal random walk (no fees, taxes, or rebalancing) so prices can't go negative, calibrated so the median path tracks the same "Base" assumption as the Compounding map. The median often lands below the smooth compounding line — that's volatility drag, not an error. Real markets have fatter tails than a normal distribution, so extreme outcomes are more likely than this model suggests. Not investment advice.

Calendar XIRR

Money-weighted return isolated to each calendar year — last year's 31 Dec value becomes this year's starting cash flow. New years appear automatically as you add transactions.

Monthly returns

Every month's return, colour-coded — darker means a bigger move either way. The Year column is the compound of that row's own months, not a separate calculation.

DCA backtest

A fixed monthly amount invested into your current allocation over each window, against the same schedule into each index. Because it applies today’s weights backwards, it flatters whichever holding has already run up — it is an illustration of the allocation, not a track record.
